# The Source Library

**The important thing isn't how many tools exist. It's what you can make them do together.**

**Provenance is not endorsement.** A saved repository is not necessarily Brad's original work. An external reference has not necessarily passed licensing, security, or compatibility checks. See the [editorial method](METHOD.md).

## What the review labels mean

- **readme_inspected:** A portion of a README was inspected, not source-code or security audited.
- **linked_in_composition:** A project is referenced as a proposed component; integration is untested.
- **inventory_only:** The repository was recorded from an accessible account inventory.
- **editorial_lead:** The project's existence was identified for research; its implementation remains unverified.

The `origin` property distinguishes original public projects from third-party references; review depth is a separate dimension. Every source must be individually checked before its code is copied, executed, or distributed.

A useful next milestone is an audited subset with exact upstream commit, verified license, maintained APIs, tested skill entrypoints, and repeatable demo results. Do not infer this from GitHub popularity.
