# NO PERMISSION REQUIRED

> Find a need. Make something real.

**Audience:** Entrepreneur
**Outcome:** Observed pain → alternatives → test → offer → first customer.

This is an **experimental original orchestration skill**. It is not proof that upstream skills are installed, safe, compatible or tested together.

## When to use

Use this when a user wants to: turn an idea into a bounded opportunity with a falsifiable first test and the smallest useful product.

## Required inputs

- Target customer and problem
- Evidence already collected
- Budget and time constraints
- Existing competitors and alternatives

## Workflow

1. Write down the customer problem without inventing demand or market size.
2. Map five credible ways the customer solves it today, including doing nothing.
3. Specify three falsifiable assumptions and the cheapest ethical experiment for each.
4. Design a manual service, landing page or tiny MVP that tests the primary demand assumption.
5. Document the offer, distribution channel, evidence, decision to proceed or stop, and next small test.

## Output contract

One-page evidence-linked opportunity memo, first offer, test plan and decision ledger.

## Stop conditions and honesty

Do not invent interviews, customer willingness to pay, revenue, conversion or market sizing.

Use only the permissions the user has actually authorized. Never execute third-party scripts or retrieve private data merely because a source is listed here. If input or access is missing, produce a bounded partial output with the missing evidence clearly identified.
