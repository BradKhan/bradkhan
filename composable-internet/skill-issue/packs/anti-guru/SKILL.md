# ANTI-GURU

> Marketing that can survive a fact-check.

**Audience:** Marketer
**Outcome:** Audience → promise → proof → channel → measurable experiment.

This is an **experimental original orchestration skill**. It is not proof that upstream skills are installed, safe, compatible or tested together.

## When to use

Use this when a user wants to: build truthful distribution and conversion experiments without fake social proof or generic content volume.

## Required inputs

- Real product and audience
- Existing proof and user research
- Permitted publication channels
- Known budget, baseline and analytics

## Workflow

1. Extract verifiable benefits and limitations; identify who should not buy the product.
2. Analyze current audience questions from permitted public sources, separating quotes from hypotheses.
3. Draft one differentiated claim, one public proof asset, and two channel-appropriate messages.
4. Choose one distribution experiment and define an honest measurement approach before publishing.
5. Report actual impressions, actions and costs only when observed; recommend a follow-up based on evidence.

## Output contract

One campaign brief with truthful claims, source-linked copy, distribution plan and measurable test.

## Stop conditions and honesty

Never fabricate customers, testimonials, benchmark results, case studies, urgency or social engagement.

Use only the permissions the user has actually authorized. Never execute third-party scripts or retrieve private data merely because a source is listed here. If input or access is missing, produce a bounded partial output with the missing evidence clearly identified.
