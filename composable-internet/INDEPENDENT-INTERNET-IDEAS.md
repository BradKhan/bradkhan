# Independent Internet: project ideas

Captured November 2, 2026. These are product hypotheses, not completed products or verified claims of novelty.

| Idea | Proposition | Smallest credible demonstration | Related assets |
| --- | --- | --- | --- |
| [Mindport](https://github.com/BradKhan/mindport) | Take useful AI context between providers while retaining local ownership | Explicitly select ChatGPT excerpts, redact, and export an independently readable context pack | Humetheus, Composable Internet C11 |
| Internet Archaeologist | Trace an idea through public documents and technological history | Reconstruct one claim's provenance with inspectable primary sources and disputed links marked | Research Trails |
| The Composable Machine | Assemble useful software from existing open-source components based on an expressed goal | One tested reproducible composition with license and integration evidence | [Composable Internet](../README.md), Stack Mutiny |
| Power Map | Explore documented ownership, capital and institutional relationships | A sourced corporate ownership graph with relationship types and uncertainty | Cyber Agency intelligence |
| Escape Hatch | Assess and execute software migration away from a proprietary provider | Export one workflow, import into an open system, and compare integrity | Software Exit Guide |
| AutoVenture | Apply autonomous experimentation to business hypotheses | Traceable multi-hypothesis research with evidence, user-controlled budgets and human review | [Venture Method](https://github.com/cyberagencyorg/venturemethod) |
| Agent X-Ray | Audit what an AI agent actually accessed, changed, and verified | A replayable tool-action audit and test report for one agent run | Open ASS, Agent Receipts |
| The Independent Internet | Composable personally controlled software, memory and infrastructure | An opt-in demonstration assembling a private usable software environment | Mindport, Humetheus, Stack Mutiny |

## Priority

1. **Mindport**: immediate usable local-first release.
2. **Internet Archaeologist**: public demonstration with unusually interesting output.
3. **Composable Machine**: ambitious multi-project flagship, after one deterministic proof.
4. **Power Map, Escape Hatch, AutoVenture, Agent X-Ray**: maintain as research candidates with explicit evidence gates.

## Publication standard

One sentence a non-developer can understand; publicly reproducible demonstration; exact reused upstream code and license provenance; meaningful user outcome; tests; known limitations. Research before declaring novelty. Don't confuse concept volume with shipped software.
